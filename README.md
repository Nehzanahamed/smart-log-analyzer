# smart-log-analyzer
A modular Python Smart Log Analyzer built to understand system log analysis while practicing core Python concepts such as file handling, functions, loops, conditionals, modules, data processing, report generation (CSV/HTML), dashboards, and data visualization using Matplotlib.

# Smart Log Analyzer

## Description
Smart Log Analyzer is a Python application that analyzes multiple log files and generates reports.

## Features
- Analyze multiple log files
- Search logs
- Show ERROR logs
- Filter by date
- Filter by time
- Filter by log level
- Find most frequent errors
- Sort logs
- Export CSV report
- Export HTML report
- Generate Dashboard
- Generate Charts

## Technologies
- Python
- Matplotlib

## Project Structure
- main.py
- analyzer.py
- reports.py
- charts.py
- config.py

## How to Run

python main.py
